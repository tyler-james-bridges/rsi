# Q1-Q195 decision traceability

## How to read this table

Every accepted question has a unique normative decision ID, `DEC-Qnnn`, and maps to
one or more stable family requirements in the v1 contract.

Evidence status:

- **I — implemented (offline/narrow):** current code and tests materially implement
  the stated narrow control. This is not a readiness label.
- **P — partial:** a relevant primitive exists, but the accepted production control
  is incomplete.
- **C — contracted:** the rule is specified here; runtime, provider, host, or
  qualification evidence is planned.
- **B — boundary:** the decision is a prohibition, scope, or authority boundary;
  current code may support it defensively, but operational verification remains.
